# Cached UCI Heart Disease data

`processed.cleveland.data` is an unchanged copy downloaded October 13, 2026 from the [original UCI endpoint](https://archive.ics.uci.edu/ml/machine-learning-databases/heart-disease/processed.cleveland.data).

Attribution: Janosi, A., Steinbrunn, W., Pfisterer, M., & Detrano, R. (1989). *Heart Disease* [Dataset]. UCI Machine Learning Repository. [DOI 10.24432/C52P4X](https://doi.org/10.24432/C52P4X). Principal Cleveland investigator: Robert Detrano.

[UCI dataset page](https://archive.ics.uci.edu/dataset/45/heart+disease) explicitly lists [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). No changes were made to this raw file. The notebook derives labels and age bands while preserving the original measurements.
